This page is ready to be adapted to a public HTTPS support page before App Store submission.

## Quick help

### Notifications do not arrive

Open iPhone Settings → Notifications → Chain and allow notifications. A reminder needs a task time and must be scheduled in the future.

### Gate cannot select or protect apps

Expo Go cannot use Family Controls. The native Chain build will request Screen Time authorization and present Apple's private app picker. Access can be reviewed in iPhone Settings.

### Restore a purchase

Open Chain → Settings → Chain Plus → Restore purchases. This becomes operational when StoreKit products are configured.

### Remove local data

The production build must include a clear in-app erase-data action before launch. Deleting the app also removes current local-only data.
